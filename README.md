# Black Forest Shop - public Android APKs

Sideload builds of **Black Forest Shop** for phones. App source stays in the private [`blackforest-android`](https://github.com/BlackForestPorsche/blackforest-android) repo.

Same download pattern as Tools Setup on [`shop-desktop`](https://github.com/BlackForestPorsche/shop-desktop) releases.
